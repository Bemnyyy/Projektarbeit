# Projektarbeit

Dieses Repository enthält eine Projektarbeit, die hauptsächlich in Jupyter Notebooks umgesetzt wurde. Der Fokus liegt auf datenanalytischer Verarbeitung und Programmierung mit Python.

## Projektbeschreibung

Das Projekt umfasst Analysen, Visualisierungen und Programmieraufgaben, die in Jupyter Notebooks dokumentiert sind. Es werden verschiedene Methoden der Datenverarbeitung und -auswertung angewandt.

## Technologien

- Jupyter Notebook
- Python
- Weitere Abhängigkeiten sind in den Notebooks dokumentiert.

## API Scraping Hinweise

Für die Verwendung der API-Scraping-Skripte in diesem Projekt ist es notwendig, eigenständig einen Account bei OpenWeatherMap oder Meteostat zu erstellen. Dort muss ein API-Key generiert werden, der für die Abfrage der Wetterdaten erforderlich ist.

Anschließend ist eine Konfigurationsdatei zu erstellen, die diese API-Keys enthält, damit die Scraping-Skripte darauf zugreifen können.
